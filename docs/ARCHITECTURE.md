## 模块职责

### 1. 前端层 (frontend/admin-web/)
- **技术**: Vue 3 + Vite + Element Plus + Pinia
- **职责**: 用户交互、数据展示、图表可视化
- **页面**: 登录、数据概览、知识管理、知识图谱、模型管理、数据管理、诊断记录、系统设置

### 2. 后端层 (backend/)
- **API Layer**: RESTful 接口定义，按业务模块拆分
- **Service Layer**: 业务逻辑实现
- **数据存储**: JSON 文件（可扩展为数据库）

### 3. 共享层 (shared/)
- 路径管理、配置常量、模型定义
- 供后端服务和训练脚本共用

### 4. 模型层 (lsnet/)
- **训练**: train.py 入口，支持多种模型
- **推理**: inference.py 提供 Python API
- **模型**: LSNet（自研轻量级网络）
- **数据**: 7:1:2 划分 + PlantVillage 集成

## 数据流

### 训练流程
```
原始数据 (lsnet/data/data1/)
   ↓
数据加载 (data/dataset.py)
   ↓
数据增强 (data/transforms.py)
   ↓
模型训练 (models/lsnet.py)
   ↓
权重保存 (checkpoints/)
   ↓
结果记录 (results/)
```

### 推理流程
```
用户上传图片
   ↓
后端接收 (api/model.py)
   ↓
调用推理 (lsnet/inference.py)
   ↓
知识图谱匹配 (services/knowledge_graph.py)
   ↓
RAG 生成建议 (services/rag_engine.py)
   ↓
返回诊断结果
```

## 技术选型理由

| 选项 | 理由 |
|------|------|
| Vue 3 | 组合式 API + 更好的 TypeScript 支持 |
| Element Plus | 成熟的中后台 UI 组件库 |
| vis-network | 专门的关系图谱可视化库 |
| Flask | 轻量、灵活、易部署 |
| LSNet | 自研轻量级网络，参数小、推理快 |
| YAML 配置 | 训练参数可读、可版本管理 |
| JSON 存储 | 简单、便于调试，可平滑迁移到数据库 |

## 扩展方向

1. **数据库**: 替换 JSON 为 PostgreSQL/MongoDB
2. **消息队列**: 引入 Celery 处理长任务
3. **容器化**: Docker + docker-compose
4. **LLM 集成**: 接入 GPT-4/Claude 提升 RAG 能力
5. **多租户**: 用户系统 + 权限管理
6. **监控**: Prometheus + Grafana
